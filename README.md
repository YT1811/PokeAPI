# Pokédex

Et enkelt Pokédex-prosjekt laget med HTML, CSS og JavaScript.  
Prosjektet bruker PokeAPI for å hente informasjon om Pokémon.

## Funksjoner
- Søk etter Pokémon med navn eller ID
- Viser navn, bilde, type, høyde, vekt og moves
- Forrige / Neste-knapper for å bla mellom Pokémon
- Pokémon-lyd (cry) når den vises
- Feilmelding ved ugyldig søk
- Mobilvennlig design

## Teknologier
- HTML
- CSS
- JavaScript
- PokeAPI

## Formål
Prosjektet demonstrerer bruk av asynkron JavaScript (async/await) og API-håndtering.
